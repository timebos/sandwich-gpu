# Видеопроцессор «Бутерброд» (Sandwich GPU)

Концепция экспериментального вычислительного модуля от **Позитрона**, **Чака (ChatGPT)** и **Грока**.

> Идея родилась за пивом, в кругу друзей. Но инженерия в ней настоящая.

## Суть

Один вертикальный картридж, который вставляется в горизонтальную материнскую плату через разъём **PCIe x16** под углом 90 градусов — как старый Intel Pentium II Slot 1. Картридж можно снять и заменить на более продвинутый, не трогая остальную систему.

## Конструкция

```
[Левый радиатор] | [Центральная плата] | [Правый радиатор]
```

- **Центральная плата**: чёрный текстолит с графическим процессором уровня RTX 4070 Ti
- **Память**: два стека HBM3E по 36 ГБ на кремниевом интерпозере — итого **72 ГБ** видеопамяти
- **Контроллер памяти**: проектируется заново под HBM вместо GDDR6X
- **CPU**: отдельный блок (например, 8-ядерный Zen 4) на том же интерпозере — как AMD MI300A. CPU и GPU делят один пул HBM без копирования через PCIe
- **Теплоотвод**: комбинированный теплораспределитель из меди и высокотеплопроводного графита, контактирующий с чипом через термоинтерфейс
- **Испарительные камеры**: по одной с каждой стороны модуля
- **Радиаторы**: два массивных алюминиевых, слева и справа
- **Вентилятор**: ровно один, на общем переднем торце обеих половин — гонит воздух горизонтально спереди корпуса назад через оба радиатора
- **Рама**: отдельная металлическая конструкция поддерживает массу, не давя на чип
- **Охлаждение**: только воздушное, без водянки

## Зачем это нужно

1. **Локальный рендер нейросетей** — 72 ГБ HBM позволяют гонять Flux, SDXL, видеомодели целиком, без квантизации. Пропускная способность HBM3E (~2.5 ТБ/с на два стека) в 5 раз выше GDDR6X — тензорные ядра не голодают.
2. **Игры** — HBM бьёт GDDR6X по пропускной способности, текстуры и ассеты в одном пуле с CPU.
3. **Апгрейд через слот** — через 5 лет вытащил старый картридж, воткнул новый с HBM4.
4. **Без цензуры** — всё локально, на своём железе.

## Слабые места (честно)

- Тепловая асимметрия: кристалл отдаёт тепло в основном в одну сторону, вторая испарительная камера работает на остаток
- Механика: 150–200+ грамм на одном PCIe-разъёме, вибрация и тепловое расширение
- HBM3E + GPU + CPU на одном интерпозере — уровень TSMC, не домашней сборки. Для частника — через фаундри (GlobalFoundries, Samsung) или петицию
