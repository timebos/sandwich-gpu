# sandwich-gpu
Концепция экспериментального видеопроцессора «Бутерброд» от Чака, Позитрона и Grok: вертикальный PCIe-картридж с GPU уровня RTX 4070 Ti, двумя стеками HBM3E (72 ГБ) на кремниевом интерпозере, двусторонним охлаждением (медь+графит, испарительные камеры, радиаторы) и одним торцевым вентилятором. Для локального рендера нейросетей и игр.
